## Pico Specs

Some general specs from https://pip-assets.raspberrypi.com/categories/1088-raspberry-pi-pico-2-w/documents/RP-008304-DS-2-pico-2-w-datasheet.pdf

### Pico 2 W
- 520kB SRAM
- 16kB on-chip cache
- 4MB flash memory
- 2.4GHz wireless interface (Wi-Fi 4 + Bluetooth)
- 40-pin PCB (26 GPIO)
